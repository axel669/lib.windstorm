# Text

Do you need to use this special element just to display text? No.

This element is really just a span with some property shorthands to adjust the
size (like the `hX` tags but without arbitrary numbers) and sometimes extra
padding around the content.

## Attributes

### title
Used for titles of pages. Uses `--font-size-title` from the theme, adds padding.

### header
Used for headers of page sections. Uses `--font-size-header` from the theme,
adds padding.

### subtitle
Used for text that fits nicely under titles. Uses `--font-size-subtitle` from
the theme, adds padding.

### info
Used for text that adds information to nearby text while being smaller. Uses
`--font-size-info` from the theme.
