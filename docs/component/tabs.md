# Tabs
- _colorized_
- _variants: fill_

Displays a list of tabs with some default styling. Tabs use hidden input tags
(the component hides the tags for you) to determine which tab is selected. The
hidden input tags need to be `type="radio"` for the tabs to work properly, and
normal form/radio input names behavior.

> The outer tab element uses a grid layout, so vertical tabs can be achieved by
> changing the grid layout behavior.
