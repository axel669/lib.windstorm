# Components
Windstorm has a number of customized elements and custom elements built-in to
help make things easier. Most components just use the macro system for
ustomization, but a few will use additional html attributes. Documentation for
each component will list what attributes it uses, and whether or not it
interacts with the colors (not all components use coloration by default).

Components with colorization and variants will list those properties above the
description on their indivudual docs, like this:

- _colorized_
- _variants: filled, outlined, etc_
